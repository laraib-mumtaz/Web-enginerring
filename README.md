# My Portfolio

My Portfolio is a personal portfolio website for Laraib Mumtaz, a computer science student at IIUI University and aspiring front-end developer. Visitors can learn about her, see her skills and projects, and send a message through the contact form. It was created to showcase her work and demonstrate web development concepts using HTML, CSS, and JavaScript.

## Features

- **Sections:** Home, About Me, My Skills, My Projects, and Contact Me.
- **Smooth Scrolling:** Navigation links glide to each section instead of jumping.
- **Light/Dark Mode:** A toggle button switches the page between light and dark themes.
- **Read More / Read Less:** Expand or collapse extra text in the About section.
- **Project Table:** Lists each project with its technologies and year, and highlights rows on hover.
- **Contact Form:** Includes validation for empty fields and invalid emails, and shows a popup message on submit.
- **Character Counter:** Shows how many characters remain in the message box (100 maximum).
- **Back to Top Button:** Appears after scrolling down and returns you to the top smoothly.

## How to Run the Project

You can view the live project directly here:

[My Portfolio Live Demo](https://laraib-mumtaz.github.io/Web-enginerring/) 

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The website will open in your default web browser.

**Note:** Keep `index.html`, `style.css`, `script.js`, and the profile image in the same folder so everything loads correctly. For the best experience, use a modern browser like Google Chrome or Mozilla Firefox.
